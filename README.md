# 🚢 Titanic Survival Prediction

## 📌 Project Overview

This project predicts whether a passenger survived the Titanic disaster using Machine Learning.

The Titanic dataset contains information about passengers such as age, gender, passenger class, fare, and other features. The goal of this project is to build a machine learning model that can predict passenger survival.

## 🎯 Objective

The main objective of this project is to:

- Analyze the Titanic passenger dataset
- Perform data preprocessing
- Explore important features
- Train a Machine Learning model
- Predict passenger survival
- Evaluate the performance of the model

## 📊 Dataset

The dataset contains information about Titanic passengers.

Important features include:

- PassengerId
- Survived
- Pclass
- Name
- Sex
- Age
- SibSp
- Parch
- Ticket
- Fare
- Cabin
- Embarked

### Target Variable

**Survived**

- `0` = Did not survive
- `1` = Survived
